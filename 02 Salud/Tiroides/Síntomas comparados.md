# Síntomas comparados

| Zona | 🐢 Hipo (lenta) | 🐇 Hiper (acelerada) |
|---|---|---|
| Energía | Cansancio, sueño excesivo | Inquietud, fatiga con insomnio |
| Peso | Sube (con mismo apetito) | Baja (con más apetito) |
| Temperatura | Frío constante | Calor, sudor |
| Corazón | Pulso lento | Palpitaciones, pulso rápido, arritmias |
| Ánimo | Depresión, apatía, niebla mental | Ansiedad, irritabilidad, nerviosismo |
| Digestión | Estreñimiento | Diarrea, evacuaciones frecuentes |
| Piel y pelo | Piel seca, pelo frágil, caída, uñas quebradizas | Piel fina/húmeda, caída de pelo |
| Periodo | Abundante / irregular | Escaso / irregular / ausente |
| Músculos | Calambres, dolor articular | Temblor, debilidad |
| Cuello | Bocio posible | Bocio posible |
| Otros | Voz ronca, hinchazón de cara, colesterol alto | Ojos prominentes (Graves), intolerancia al calor |
| Sueño | Mucho sueño | Insomnio |

## Perimenopausia: se parece mucho
Cansancio, niebla mental, cambios de ánimo, peso, sueño malo, caída de pelo, dolor articular, cambios de temperatura y de periodo. **No se distinguen por síntomas: hacen falta análisis** (TSH, T4 libre; ver [[Diagnóstico y análisis]]).

## Señales de ir pronto al médico
Bulto en el cuello, ronquera que no pasa, dificultad para tragar o respirar, palpitaciones fuertes, pérdida de peso sin explicación, cansancio extremo de semanas.
